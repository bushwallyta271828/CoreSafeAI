# People photos

Store profile photos for the People page in this directory. Use a short,
lowercase filename, then reference it from `people.html`, for example:

```html
<img src="photos/name.jpg" alt="Person's name" width="120" height="120">
```

Square or portrait-oriented images work best. The site displays them as a
120-by-120-pixel circle and crops them with `object-fit: cover`.
